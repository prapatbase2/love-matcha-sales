# Love Matcha Sales v1.4.3

อัปเดตวันที่ 26/09/2026 โดยยึด v1.4.2 เป็นฐาน และเพิ่ม field แบบ backward-compatible ไม่ลบ collection หรือ document เดิม

## หน้ายอดขาย
- เพิ่มช่อง `Voucher` แยกจาก `ส่วนลด` ค่าเริ่มต้น 0 และแก้ไขได้
- สูตร `รายได้รวม = ยอดขายก่อนส่วนลด - ส่วนลด - Voucher`
- `รายได้รวมทั้งหมด = รายได้รวม + Line Man + Grab` จึงได้รับผลจาก Voucher ตามต้องการ
- เพิ่ม/ย้าย `หมายเหตุ` ให้เป็นช่องสุดท้ายในส่วนข้อมูลยอดขาย และยังเก็บใน field `note` เดิมเพื่อรักษาข้อมูลย้อนหลัง
- วันหยุดร้านยังสามารถใส่หมายเหตุได้
- บันทึก dailySales แบบ merge เพื่อรักษา field/metadata เดิมที่มีอยู่ใน document

## Dashboard
- เพิ่มยอดรวม `Voucher ที่ใช้`
- ตารางรายการล่าสุดเพิ่มคอลัมน์ Voucher

## รายเดือน
- เพิ่ม KPI `Voucher ที่ใช้รวม`
- ตารางรายวันเพิ่มคอลัมน์ Voucher และหมายเหตุ
- วันที่มีเงินสดขาด/เกินจะเน้นสี มีป้าย `⚠ ตรวจเงินสด` พร้อมจำนวนเงิน และปุ่มให้เปิดตรวจรายละเอียด
- หัวสาขาแสดงจำนวนวันที่พบเงินสดขาด/เกิน
- รายละเอียดรายวันเพิ่มบรรทัด Voucher
- Export CSV เพิ่มคอลัมน์ `voucher`

## เช็คชื่อ
- เพิ่มช่อง `หมายเหตุ` โดยไม่บังคับกรอก
- ตารางเช็คชื่อแสดงหมายเหตุที่พนักงานบันทึกไว้

## ความเข้ากันได้กับข้อมูลเดิม
- ข้อมูล dailySales เดิมที่ไม่มี `voucher` จะอ่านค่าเป็น 0 อัตโนมัติ
- ไม่ต้อง migrate ฐานข้อมูล และไม่มีการลบข้อมูลเดิมตอนอัปโหลดไฟล์เว็บ
- Full Backup JSON เดิมยัง Restore ได้ เพราะระบบใช้โครงสร้าง collection เดิมและเพิ่ม field เท่านั้น
- Google Apps Script Backup v1.4.2 แบบ JSON-only เดิมยังใช้งานร่วมกับแอป v1.4.3 ได้ ไม่จำเป็นต้อง Deploy ใหม่เพราะอัปเดตนี้
