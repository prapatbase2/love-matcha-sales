# Love Matcha Sales v1.4.1

อัปเดตจาก v1.4.0 ตามรายการที่ขอ

## สิ่งที่แก้ไข

1. หน้าตั้งค่า / สาขา
- อัปเดตเวอร์ชันเป็น v1.4.1
- เจ้าของสามารถลบสาขาได้เท่านั้น
- ก่อนลบสาขาต้องกรอก PIN เจ้าของยืนยัน
- การลบสาขาเป็นการซ่อน/ปิดใช้สาขา ไม่ลบข้อมูลยอดขาย รายจ่าย หรือข้อมูลเดิมของสาขานั้น
- ถ้าสร้างสาขาชื่อเดิมกลับมา ระบบจะพยายามใช้ branch id เดิม เพื่อให้ข้อมูลเก่ากลับมาใช้ต่อได้

2. หน้าแดชบอร์ด
- ปรับสูตร “รายได้หลังหักค่าใช้จ่าย” เป็น:
  (รายได้รวม / 2) - รายจ่ายขาย - รายจ่ายเจ้าของลง
- ใช้แนวคิดสมมติต้นทุนวัตถุดิบเท่ากับ 50% ของยอดขายรวม

3. หน้าลงรายจ่าย
- ช่อง “เป็นของ” ของรายจ่ายประจำและรายจ่ายอื่น เปลี่ยนเป็นช่องเดียว
- เลือกได้เลยว่าเป็น “รวมทุกสาขา” หรือสาขาใดสาขาหนึ่ง
- เอาช่องเลือกสาขาแยกออก ลดพื้นที่ในหน้าจอมือถือ

4. รายจ่ายประจำอัตโนมัติจากค่าตอบแทน
- ถ้าพนักงานอยู่ทุกสาขา: คิดเป็นภาระรวมทุกสาขา และกระจายตามสัดส่วนยอดขาย
- ถ้าพนักงาน/รายวันอยู่หลายสาขาแต่ไม่ครบทุกสาขา: กระจายต้นทุนตามวันที่ทำงานจริงในสาขาที่ถูกลงชื่อในหน้ายอดขาย
- ถ้ามีสาขาเดียว: ลงภาระสาขานั้นโดยตรง

5. หน้าเช็คชื่อ
- เฉพาะสาขาหนองคาย เพิ่มเวลาพาร์ทไทม์ Rendo ให้เลือกได้ 18:00-24:00 ทีละครึ่งชั่วโมง
- ไอดี/ชื่อ Lek ไม่แสดงคำเตือนย้อนหลังว่าไม่ได้เช็คชื่อ

6. หน้าค่าตอบแทน
- ตัดคำอธิบายยาวใต้ตารางค่าตอบแทนหัวหน้างาน/พนักงานออก
- ปรับ PDF สรุปค่าตอบแทนให้ครบถ้วน อ่านง่าย และเหมาะกับ 1 หน้า A4
- สร้าง PDF จากหน้า export แยก ลดโอกาสข้อมูลโดนตัดจากกล่องเลื่อนในมือถือ

7. ความเร็ว/โหลดไฟล์
- อัปเดต service worker cache เป็น v1.4.1 เพื่อบังคับเครื่องที่เคยเปิดเวอร์ชันเก่าให้โหลดไฟล์ใหม่
- ลดช่องกรอกซ้ำในหน้ารายจ่าย ทำให้หน้าสั้นลงและใช้งานบนมือถือเร็วขึ้น

## วิธีอัปเดต

1. แตก ZIP นี้
2. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub repository
3. รอ GitHub Pages deploy เสร็จ
4. เปิดเว็บแล้วตรวจว่าแสดง v1.4.1
5. บนมือถือ ถ้ายังเห็นเวอร์ชันเก่า ให้ปิดแอป/ปิดแท็บ แล้วเปิดใหม่ หรือกด refresh 1-2 ครั้ง

## หมายเหตุ

การลบสาขาไม่ได้ลบข้อมูลเก่าใน Firestore ข้อมูลยอดขาย/รายจ่ายของสาขานั้นยังอยู่ หากต้องการใช้งานอีกครั้งให้เพิ่มสาขาด้วยชื่อเดิม ระบบจะพยายามกู้ branch id เดิมกลับมา
